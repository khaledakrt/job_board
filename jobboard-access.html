Acces Database Depuis Ton PC

Ouvre ce tunnel dans PowerShell et laisse la fenetre ouverte:

ssh -L 3307:127.0.0.1:3306 root@5.189.190.131

Ensuite, dans MySQL Workbench, DBeaver ou TablePlus:

Host: 127.0.0.1
Port: 3307
Database: job_board
User: valeur DB_USER dans /var/www/jobboard/backend/.env
Password: valeur DB_PASSWORD dans /var/www/jobboard/backend/.env
Ne rouvre pas le port public 3306. Le tunnel SSH est plus securise.

Commandes App / PM2

# Voir l'app Node
runuser -u jobboard -- pm2 list

# Logs backend
runuser -u jobboard -- pm2 logs jobboard-api

# Redemarrer proprement l'app
systemctl restart pm2-jobboard

# Tester localement depuis le VPS
curl http://127.0.0.1:3001/api/health
Important: evite pm2 start en root pour cette app. Utilise systemctl restart pm2-jobboard.

Workflow MAJ / Git / Prod

Utilise ce flow quand tu fais une mise a jour du code: PC local vers GitHub, puis pull/update sur le VPS Contabo.

1. Sur ton PC local

cd D:\khaled\Cursor
git status
git add .
git commit -m "Message clair de la mise a jour"
git push

2. Se connecter au VPS Contabo

ssh root@5.189.190.131
cd /var/www/jobboard

3. Verifier avant update

git status --short
systemctl status pm2-jobboard
runuser -u jobboard -- pm2 list
curl http://127.0.0.1:3001/api/health

4. Pull + update backend/frontend

cd /var/www/jobboard
git pull

# Backend
cd /var/www/jobboard/backend
npm ci --omit=dev
npm run db:migrate

# Frontend
cd /var/www/jobboard/frontend
npm ci
npm run build

# Copier le build Angular vers site/
rm -rf /var/www/jobboard/site/*
cp -r /var/www/jobboard/frontend/dist/job-board-frontend/browser/* /var/www/jobboard/site/

5. Redemarrer l'API correctement

systemctl restart pm2-jobboard
systemctl status pm2-jobboard
runuser -u jobboard -- pm2 list

6. Tests apres deploy

curl http://127.0.0.1:3001/api/health
curl https://tun-job-board.com/api/health

# Depuis ton PC local, tu peux aussi lancer:
cd D:\khaled\Cursor
npm run test:smoke:prod
Attention: ne relance pas l'app avec pm2 start en root. Le service officiel est pm2-jobboard et il lance l'API avec le user Linux jobboard.
