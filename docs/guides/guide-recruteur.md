# Guide d’utilisation recruteur

Bienvenue dans l’espace recruteur de Tun Job.

Ce guide accompagne les recruteurs et les responsables RH dans l’utilisation de la plateforme : création du profil entreprise, publication des offres, suivi des candidatures, gestion de l’équipe et consultation des archives.

## 1. Accéder à l’espace recruteur

1. Ouvrez le lien d’invitation reçu par e-mail.
2. Connectez-vous avec votre adresse professionnelle.
3. Accédez au menu recruteur depuis votre tableau de bord.

Si votre société n’est pas encore configurée, la plateforme vous invite à compléter le profil entreprise avant d’utiliser toutes les fonctionnalités.

## 2. Menu principal

Le menu recruteur contient les principales rubriques de travail :

- **Tableau de bord** : vue globale de l’espace recruteur, actions rapides et priorités.
- **Entreprise** : fiche société, logo, informations publiques et coordonnées.
- **Équipe** : invitation et gestion des permissions des recruteurs.
- **Offres** : création, modification, publication et archivage des annonces.
- **Candidatures (ATS)** : suivi des candidats par offre et par étape.
- **Archives** : historique des candidatures rejetées et offres archivées ou expirées.
- **Paramètres** : accès aux réglages du compte.

## 3. Tableau de bord

Le tableau de bord est le point de départ de votre activité.

### Boutons principaux

- **Créer une offre** : ouvre le formulaire de publication d’une nouvelle annonce.
- **Traiter les candidatures** : ouvre l’ATS pour suivre les candidats.
- **Voir / compléter le profil entreprise** : permet de gérer votre vitrine employeur.
- **Gérer l’équipe** : disponible pour le responsable de l’espace société.

### Conseils

- Vérifiez régulièrement les actions recommandées.
- Complétez le profil entreprise avant de publier vos premières offres.
- Utilisez l’accès rapide à l’ATS dès qu’une candidature arrive.

## 4. Profil entreprise

La page **Entreprise** permet de présenter votre société aux candidats.

### Informations importantes

- **Nom commercial / marque employeur** : nom affiché publiquement.
- **Raison sociale** : information légale si différente du nom commercial.
- **Forme juridique, année de création, SIRET, TVA** : informations administratives.
- **Adresse, ville, pays** : localisation de la société.
- **E-mail RH et téléphone** : coordonnées de contact.
- **Site web et LinkedIn** : liens de confiance pour les candidats.
- **Secteur d’activité, taille, description** : informations utiles pour attirer les profils.
- **Logo** : affiché sur les offres et la page entreprise.

### Boutons et options

- **Public / Privé** à côté de l’e-mail et du téléphone : choisit si la donnée est visible sur la page publique.
- **Logo** : permet d’ajouter ou remplacer l’identité visuelle.
- **Enregistrer** : sauvegarde les modifications.

Si vous voyez le message “Consultation seule”, vous n’avez pas le droit de modifier l’entreprise. Demandez au responsable RH de vous accorder la permission correspondante.

## 5. Gestion de l’équipe

La page **Équipe** permet au responsable de société d’inviter d’autres recruteurs.

### Inviter un recruteur

1. Cliquez sur **Inviter un recruteur**.
2. Saisissez l’e-mail professionnel.
3. Ajoutez le poste et le téléphone si nécessaire.
4. Sélectionnez les permissions initiales.
5. Cliquez sur **Envoyer l’invitation**.

### Permissions disponibles

- **Publier des offres** : permet de créer, modifier, publier, masquer ou archiver des annonces.
- **Traiter les candidatures** : permet d’accéder à l’ATS et de changer les étapes des candidats.
- **Modifier l’entreprise** : permet de mettre à jour la fiche société.

### Actions sur un membre

- **Modifier** : ajuste le poste, le téléphone et les permissions.
- **Retirer** : retire l’accès du membre à l’espace société.

## 6. Gestion des offres

La page **Offres** liste toutes les annonces de la société.

### Filtres et lecture

- **Filtrer par statut** : affiche les offres selon leur état.
- **Vues** : nombre de consultations de l’annonce.
- **Candidats** : nombre de candidatures reçues.
- **Expiration** : date ou état d’expiration.

### Statuts d’une offre

- **Brouillon** : visible seulement par l’équipe recruteur.
- **Publiée / active** : visible par les candidats.
- **Masquée** : retirée de l’espace public sans supprimer l’historique.
- **Expirée** : fin automatique de publication selon la date d’expiration.

### Actions disponibles

- **Créer une offre** : ouvre le formulaire de création.
- **Modifier** : édite une offre existante.
- **Candidatures** : ouvre l’ATS filtré sur cette offre.
- **Publier** : rend l’offre visible aux candidats.
- **Masquer** : retire temporairement l’offre de l’espace public.
- **Archiver** : déplace l’offre vers l’historique.

## 7. Créer ou modifier une offre

Le formulaire d’offre permet de rédiger une annonce complète et structurée.

### Champs principaux

- **Titre** : intitulé du poste.
- **Contrat** : type de contrat.
- **Mode** : sur site, hybride ou télétravail selon les options disponibles.
- **Lieu** : ville ou zone géographique.
- **Date d’expiration** : fin de visibilité de l’annonce.
- **Statut** : brouillon, publiée ou masquée.
- **Expérience** : nombre d’années minimum.
- **Salaire** : montant libre ou fourchette min/max.
- **Devise et période** : TND, EUR ou USD, par mois/an/jour/heure.
- **Langues** : ajoutez une langue puis appuyez sur Entrée ou sur “+”.
- **Description** : missions, contexte, équipe, responsabilités.
- **Profil recherché** : compétences, diplômes, expérience attendue.
- **Skills** : mots-clés techniques ou métier.
- **Avantages** : télétravail, tickets restaurant, commissions, mutuelle, etc.

### Quiz optionnel

Le quiz permet d’ajouter 2 questions aux candidats.

- Activez **Quiz**.
- Cliquez sur **Configurer le quiz**.
- Renseignez les questions et les réponses.
- Indiquez la bonne réponse pour chaque question.

### Bouton final

- **Publier l’offre** : enregistre l’offre. Si son statut est publié, elle devient visible aux candidats.
- **Mettre à jour** : enregistre les modifications d’une offre existante.

## 8. Aperçu d’une offre

La page d’aperçu affiche l’annonce telle qu’elle sera présentée aux candidats.

Actions possibles :

- **Retour aux offres** : revient à la liste.
- **Modifier** : corrige l’annonce.
- **Candidatures** : ouvre les candidatures de cette offre.

Vérifiez toujours le titre, le lieu, le contrat, la description, les avantages et la date d’expiration avant publication.

## 9. Suivi des candidatures (ATS)

L’ATS centralise toutes les candidatures reçues.

### Modes d’affichage

- **Kanban** : vue par colonnes, pratique pour suivre le pipeline.
- **Liste** : vue tabulaire, recommandée sur mobile ou pour traiter rapidement plusieurs dossiers.

### Filtres

- **Filtrer par offre** : affiche uniquement les candidatures d’une annonce.
- **Tout afficher** : retire le filtre.

### Actions candidat

- **Profil** : ouvre les informations du candidat.
- **CV** : ouvre le CV si disponible.
- **Changer l’étape** : déplace le candidat dans le processus.
- **Note / évaluation** : permet de qualifier un profil.

Les candidatures rejetées sont automatiquement envoyées dans les archives.

## 10. Notifications

La cloche de notification signale les nouvelles candidatures.

Actions possibles :

- **Ouvrir une notification** : affiche le détail de la candidature.
- **Voir la candidature** : ouvre directement le dossier dans l’ATS.
- **Voir l’offre** : ouvre l’annonce concernée.
- **Tout marquer lu** : supprime l’indicateur de notifications non lues.

## 11. Archives

La page **Archives** conserve l’historique.

### Onglets

- **Candidatures rejetées** : candidats retirés du pipeline actif.
- **Offres archivées / expirées** : annonces anciennes ou retirées.

### Actions

- **Voir détail** : consulte l’élément archivé.
- **Restaurer** : remet l’élément dans le flux actif lorsque c’est possible.
- **Supprimer** : retire l’élément de l’historique recruteur.

## 12. Bonnes pratiques

- Utilisez un titre clair et précis.
- Ajoutez une description complète : missions, contexte, équipe et objectifs.
- Précisez le lieu, le contrat, la rémunération et les avantages.
- Gardez la fiche entreprise à jour.
- Traitez les candidatures régulièrement pour améliorer l’expérience candidat.
- Archivez les offres terminées pour garder un espace propre.
- Gérez les permissions d’équipe selon les responsabilités réelles.

## 14. Besoin d’aide

Si vous rencontrez un problème :

1. Vérifiez que votre profil entreprise est complet.
2. Vérifiez vos permissions auprès du responsable société.
3. Contactez l’administrateur de la plateforme avec une capture d’écran du message affiché.
